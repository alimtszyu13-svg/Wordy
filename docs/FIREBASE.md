# Firebase: сервер Wordy

Своего сервера у Wordy нет. Всё серверное делают сервисы Google Firebase. Здесь описано, какие сервисы используются, что лежит в базе и как устроена безопасность.

Консоль Firebase: https://console.firebase.google.com

## Два проекта

| Проект | Для чего |
|---|---|
| **wordy-b5142** | Основной: сайт (Hosting), вход, база данных, файлы, ИИ-помощник, напоминания |
| **wordy-live** | Только голосовые звонки с Ворди (Gemini Live). Вынесен отдельно, потому что звонок идёт по WebSocket, а через него браузер не может отправить проверку App Check, которая защищает основной проект |

Настройки обоих проектов лежат в начале `src/app.full.html`: `WORDY_FIREBASE` (основной) и `WORDY_LIVE` (звонки).

## Что чем сделано

| Сервис | Что делает в Wordy | Где в коде |
|---|---|---|
| **Hosting** | Раздаёт файлы сайта по адресу wordy-b5142.web.app | `firebase.json` |
| **Authentication** | Вход через Google и email. Вход через Microsoft подготовлен, но выключен | `WORDY_AUTH`, раздел `ACCOUNTS: data layer` |
| **Cloud Firestore** | База данных: профили, группы, домашки, сертификаты, отзывы, статистика | `firestore.rules`, раздел `ACCOUNTS` |
| **Cloud Storage** | Файлы к домашкам (до 20 МБ на файл). Нужен тариф Blaze | `storage.rules` |
| **Cloud Functions** | Напоминания раз в день. Код готов, но пока не выложен | `functions/index.js` |
| **AI Logic (Gemini)** | ИИ-помощник, проверка эссе и речи, истории, голосовой тест уровня | `WORDY_AI`, `WORDY_LIVE` |
| **App Check** | Пускает к ИИ только запросы с настоящего сайта Wordy (через reCAPTCHA) | `WORDY_AI.recaptcha` |

## Что лежит в базе (Firestore)

Коллекции — это «папки» в базе. Кто что может читать и писать, решают правила в `firestore.rules`, их проверяет сервер, а не браузер.

| Коллекция | Что там | Кто имеет доступ |
|---|---|---|
| `users/{id}` | Профиль: имя, роль (учитель или ученик), группы. Роль выбирается один раз | Сам человек |
| `users/{id}/private/state` | Копия прогресса для входа с другого устройства | Сам человек |
| `users/{id}/quizzes` | Викторины учителя | Сам учитель |
| `groups/{id}` | Группа учителя | Учитель и ученики группы |
| `groups/{id}/members` | Ученики группы. Вступить можно только по действующему коду или приглашению | Учитель, ученик (о себе) |
| `groups/{id}/assignments` | Домашние задания | Учитель и ученики группы |
| `.../assignments/{id}/subs` | Ответы учеников. Ученик пишет ответ, учитель — только отзыв и оценку | Учитель и автор ответа |
| `groups/{id}/games` | Живая викторина в классе. Правильные ответы лежат в `key` и ученикам не видны | Учитель управляет, ученики отвечают |
| `joinCodes/{код}` | Код дня для вступления в группу. Открыть можно только по точному коду, перебрать список нельзя | Все, у кого есть код |
| `invites/{id}` | Приглашения по email | Учитель и владелец email |
| `certs/{код}` | Сертификаты уровней. Проверяются на странице `verify.html` | Проверить по коду — любой. Выдать можно только себе, изменить нельзя |
| `feedback/{id}` | Отзывы из «Настройки → Обратная связь» и сообщения «Ошибка в задании?» | Отправить — все, прочитать — только ты |
| `errs/{день}_{id}` | Счётчики сбоев ИИ и звонков за день на устройство, без личных данных | Прочитать — только ты |
| `act/{день}_{id}` | Анонимная статистика: одна запись на устройство в день, без имён и email | Прочитать — только ты |
| `push/{id}` | Адреса устройств для напоминаний | Только сервер |

**Где читать отзывы:** Firebase Console → Firestore Database → коллекция `feedback`. Статистику Wordy ты видишь прямо в приложении: в Настройках есть раздел «Статистика Wordy», он виден только аккаунту из `WORDY_OWNER`.

## Как выкладывать правила и функции

| Что выложить | Команда | Примечание |
|---|---|---|
| Сайт | `npx firebase-tools deploy --only hosting` | Обычная выкладка |
| Правила базы | `npx firebase-tools deploy --only firestore:rules` | После правки `firestore.rules` |
| Сайт и правила вместе | `npx firebase-tools deploy` | Выкладывает всё, что указано в `firebase.json` |
| Правила файлов | Вручную: Console → Storage → Rules, вставить `storage.rules` | `firebase.json` их пока не упоминает, поэтому команда deploy их не выкладывает |
| Напоминания | Сначала добавить в `firebase.json` раздел `"functions": {"source": "functions"}`, потом `npx firebase-tools deploy --only functions`, потом в `src/app.full.html` поставить `WORDY_PUSH=true` | Нужен тариф Blaze |

## Ключи и безопасность

### Что не секрет

Ключи вида `AIza…` в `WORDY_FIREBASE` и `WORDY_LIVE` — это **публичные** ключи Firebase. Они специально лежат в коде сайта: по ним Firebase узнаёт, к какому проекту обращается браузер. Поэтому GitHub и показывает на них оповещения в Security, но это не утечка.

Защищают Wordy не секретность ключей, а три вещи:
1. **Правила** `firestore.rules` и `storage.rules`: даже с ключом нельзя прочитать чужие данные.
2. **App Check**: к ИИ пускают только запросы с настоящего сайта.
3. **Ограничения ключа** в Google Cloud Console (APIs & Services → Credentials): ключ работает только с адресов твоего сайта и только с нужными сервисами.

### Что секрет и никогда не должно попасть на GitHub

- JSON-ключи сервисных аккаунтов (например `firebase-adminsdk`).
- Ключ подписи приложения для Google Play (keystore, `.jks`) и его пароль.
- Пароли от аккаунтов Google, Firebase, Play Console.
- Отдельные ключи Gemini из AI Studio, если ты их создашь.

Если что-то такое случайно попало в репозиторий, удалить файл недостаточно: он останется в истории Git. Нужно сразу **заменить** ключ или пароль на новый в консоли сервиса.

### На что обратить внимание

- В начале `src/app.full.html` в `WORDY_OWNER` записан твой email. Так приложение узнаёт владельца, и тот же email должен стоять в `firestore.rules`. Репозиторий публичный, поэтому этот email видят все. Если хочешь его скрыть, можно заменить проверку email на проверку твоего ID пользователя (uid) — это отдельная небольшая правка.
- Поставь в Google Cloud → Billing → **Budgets & alerts** бюджет с уведомлением, хотя бы на $1. Если кто-то начнёт злоупотреблять ИИ через твой проект, ты узнаешь сразу.
