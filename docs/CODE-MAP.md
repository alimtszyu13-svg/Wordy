# Карта главного файла

Весь Wordy написан в одном файле: `src/app.full.html`, около 28 700 строк. Это много, но устроено по порядку: сверху настройки и стили, потом Ворди, потом само приложение, раздел за разделом.

**Как пользоваться картой.** Номера строк приблизительные: после любой правки они сдвигаются. Надёжнее искать через **Ctrl+F** по слову из колонки «Искать». Большие разделы в коде начинаются с заголовка-баннера вида `/* ===== НАЗВАНИЕ ===== */`.

Подсказка для VS Code: **Ctrl+Shift+O** показывает список всех функций и переменных файла, а **Ctrl+G** переходит на строку по номеру.

## 1. Начало файла: настройки и внешний вид

| Строки | Что там | Искать |
|---|---|---|
| ~16–55 | Ранний скрипт: выбор языка, загрузка Firebase, настройки проекта и ИИ, запрет отдаления на iPhone | `WORDY_LANG`, `WORDY_FIREBASE`, `WORDY_AI`, `WORDY_LIVE` |
| ~61–2750 | Все стили (CSS): цвета, светлая и тёмная темы, кнопки, карточки, экраны | `<style>`, `--accent`, `prefers-color-scheme` |
| ~2752–2760 | Заставка «Загружаем Wordy…» | `splash` |

Полезные переключатели в раннем скрипте:
- `WORDY_AUTH=['google']` — способы входа. Вход через Microsoft в коде готов, но включается добавлением `'microsoft'`, когда он настроен в Firebase.
- `WORDY_PUSH=false` — напоминания на телефон. Включаются, когда выложены `functions/` (нужен тариф Blaze).
- `WORDY_AI` — какие модели Gemini используются и в каком порядке.
